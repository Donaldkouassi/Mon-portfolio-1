# Portfolio — Kouassi Donald

Portfolio personnel développé en HTML, CSS et JavaScript, hébergé sur GitHub Pages. Il présente mon parcours, mes compétences et les projets réalisés pendant ma formation en développement web.

Site en ligne : https://donaldkouassi.github.io/Mon-portfolio-1/

## Contenu du site

- Accueil : présentation rapide et accès direct aux projets
- À propos : parcours, formations et expériences professionnelles
- Compétences : compétences techniques et comportementales, avec niveaux de maîtrise
- Portfolio : les projets réalisés
- Services : les prestations proposées
- Contact : formulaire et liens vers les réseaux

## Projets présentés

- Générateur de devis : calcul dynamique d'un devis en HTML, CSS et JavaScript
- To-Do List : application de gestion des tâches quotidiennes
- Calculatrice : calculatrice interactive en JavaScript

Le code source de chacun se trouve dans le dossier projets.

## Technologies

HTML5, CSS3 (Flexbox, Grid, responsive design), JavaScript et manipulation du DOM, Font Awesome pour les icônes, police Poppins via Google Fonts, hébergement GitHub Pages.

## Lancer le projet en local

```bash
git clone https://github.com/Donaldkouassi/Mon-portfolio-1.git
cd Mon-portfolio-1
```

Il suffit ensuite d'ouvrir index.html dans un navigateur : le site est entièrement statique, aucune installation n'est nécessaire.

## Structure du projet

- index.html, a-propos.html, competences.html, portfolio.html, services.html, contact.html : les pages du site
- style.css : feuille de styles commune
- script.js : interactions et animations
- images : photo de profil et aperçus des projets
- projets : code source des mini-projets
